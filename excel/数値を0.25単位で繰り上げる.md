Excelで数値を 0.25単位で切り上げる には、`CEILING` 関数を使用します。

### 1. 基本的な方法

```
=CEILING(A1,0.25)
```

A1セルの数値を、0.25の倍数に切り上げます。

| 元の数値 | 切り上げ後 |
| ---- | ----- |
| 0.10 | 0.25  |
| 0.25 | 0.25  |
| 0.26 | 0.50  |
| 0.50 | 0.50  |
| 0.60 | 0.75  |
| 0.76 | 1.00  |
| 1.10 | 1.25  |
| 1.26 | 1.50  |

### 2. 別の方法

`ROUNDUP` 関数でも同じ処理ができます。

```
=ROUNDUP(A1*4,0)/4
```

0.25は1/4なので、4倍して整数に切り上げた後、4で割ります。

### 3. 切り上げ・四捨五入・切り捨ての比較

| 処理   | Excelの数式            |
| ---- | ------------------- |
| 切り上げ | `=CEILING(A1,0.25)` |
| 四捨五入 | `=MROUND(A1,0.25)`  |
| 切り捨て | `=FLOOR(A1,0.25)`   |

おすすめは `=CEILING(A1,0.25)` です。

例えば、作業時間を0.25時間（15分）単位で管理する場合にも利用できます。ただし、セルに `1:10` のような時刻形式で入力している場合は、別の数式が必要です。

はい。`0.3333333` のような小数でも問題ありません。

```
=CEILING(A1,0.25)
```

例えば、次のように切り上げられます。

| 元の数値      | 結果   |
| --------- | ---- |
| 0.3333333 | 0.50 |
| 0.6666667 | 0.75 |
| 0.9999999 | 1.00 |
| 1.3333333 | 1.50 |
| 1.6666667 | 1.75 |

小数点以下の桁数に関係なく、0.25の倍数に切り上げられます。

ただし、Excelでは内部的な数値が使用されるため、表示上は `0.25` でも、実際の値が `0.25000001` なら `0.50` に切り上げられます。

計算誤差が気になる場合は、次のように先に丸める方法もあります。

```
=CEILING(ROUND(A1,7),0.25)
```

これなら、小数点以下7桁に丸めてから0.25単位に切り上げます。
