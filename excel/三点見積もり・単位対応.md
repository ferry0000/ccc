Excelで、タスクごとに 「75分」または「1.25時間」のどちらでも入力でき、最終的に人日へ換算する表 を作るなら、次の2つの方法があります。

## 方法①：1つのセルに「75分」「1.25時間」と入力する（おすすめ）

単位を含めて入力し、Excelの数式で自動判別します。

| A列：タスク | B列：作業時間（入力） | C列：人日（計算結果） |
| ------ | ----------- | ----------- |
| タスクA   | 75分         | 0.15625     |
| タスクB   | 1.25時間      | 0.15625     |
| タスクC   | 30分         | 0.0625      |
| タスクD   | 2時間         | 0.25        |
| 合計     |             | 0.625       |

※ 1人日＝8時間の場合。

### 数式

例えば、E1セルに「1人日あたりの時間」として `8` を入力します。

C2セルに以下の数式を入力してください。

```
=IF(B2="","",IF(RIGHT(B2,1)="分",VALUE(SUBSTITUTE(B2,"分",""))/60,VALUE(SUBSTITUTE(B2,"時間","")))/$E$1)
```

この数式では、入力値に応じて自動的に変換します。

- `75分` → 75 ÷ 60 ÷ 8 = 0.15625人日
- `1.25時間` → 1.25 ÷ 8 = 0.15625人日
- `2時間` → 2 ÷ 8 = 0.25人日

人日の合計は次の数式で計算できます。

```
=SUM(C2:C100)
```

## 方法②：数値と単位を別々のセルに入力する

数値は数値のまま扱い、単位をプルダウンで選択します。

| タスク  | 数値   | 単位 | 人日      |
| ---- | ---- | -- | ------- |
| タスクA | 75   | 分  | 0.15625 |
| タスクB | 1.25 | 時間 | 0.15625 |
| タスクC | 30   | 分  | 0.0625  |
| タスクD | 2    | 時間 | 0.25    |

D2セルの数式は以下です（E1に `8` を入力）。

```
=IF(OR(B2="",C2=""),"",IF(C2="分",B2/60,IF(C2="時間",B2,""))/$E$1)
```

単位のプルダウンは、C列を選択し、「データ」→「データの入力規則」→「リスト」を選び、元の値に `分,時間` と入力すれば設定できます。

## どちらがよいか

個人的には方法①をおすすめします。

入力が `75分`、`1.25時間` のように直感的で、列数も少なくできます。

ただし、単位を付けずに数値だけ入力したい 場合は、方法②が適しています。Excelでは、数値の `75` が75分なのか75時間なのかを自動的に区別できないためです。

## Excelで「三点見積もり」を時間単位で計算する方法

タスクごとに「楽観値」「最頻値」「悲観値」の3つを入力し、「時間」または「分」を選択する形式にします。

三点見積もりには、最頻値を4倍して加重平均する PERT法 を使用します。

| タスク  | 楽観値 | 最頻値  | 悲観値 | 単位 | 見積時間    |
| ---- | --- | ---- | --- | -- | ------- |
| タスクA | 30  | 60   | 90  | 分  | 1.000   |
| タスクB | 1   | 1.25 | 2   | 時間 | 1.333   |
| タスクC | 45  | 75   | 135 | 分  | 1.333   |
| タスクD | 2   | 3    | 5   | 時間 | 3.167   |
| 合計   |     |      |     |    | 6.833時間 |

### 計算式

PERT法では、以下の式を使用します。

\\[ 見積時間=\frac{楽観値+4\times 最頻値+悲観値}{6} \\]

入力単位が「分」の場合は、さらに60で割って時間へ変換します。

Excelで、B列が楽観値、C列が最頻値、D列が悲観値、E列が単位、F列が見積時間の場合、F2セルに以下の数式を設定してください。

```
=IF(OR(COUNT(B2:D2)<>3,E2=""),"",IF(E2="分",(B2+4*C2+D2)/360,IF(E2="時間",(B2+4*C2+D2)/6,"")))
```

この式は、単位が「時間」ならそのままPERT計算し、「分」なら時間へ換算します。3つの数値または単位が未入力の場合は空欄にします。

このExcelの数式は、楽観値・最頻値・悲観値の3つの数値を使って三点見積もり（PERT法）を行い、結果を「時間」単位で返すものです。

入力単位が「分」なら時間へ変換し、「時間」ならそのまま計算します。

## 1. 数式の全体構造

```
=IF(
    OR(COUNT(B2:D2)<>3,E2=""),
    "",
    IF(
        E2="分",
        (B2+4*C2+D2)/360,
        IF(
            E2="時間",
            (B2+4*C2+D2)/6,
            ""
        )
    )
)
```

各セルの意味は以下のとおりです。

| セル | 内容   | 入力例   |
| -- | ---- | ----- |
| B2 | 楽観値  | 30    |
| C2 | 最頻値  | 60    |
| D2 | 悲観値  | 90    |
| E2 | 単位   | 分     |
| F2 | 計算結果 | 1.0時間 |

## 2. 数式を分解して解説

### ① 入力が揃っているか確認

```
OR(COUNT(B2:D2)<>3,E2="")
```

それぞれの意味は以下のとおりです。

- `COUNT(B2:D2)`：B2～D2に入力された数値の個数を数える。
- `<>3`：数値の個数が3個ではない。
- `E2=""`：E2が空欄である。
- `OR(...)`：いずれかの条件が成立すればTRUEを返す。

この条件は、3つの数値が揃っていない、または単位が未入力である場合にTRUE になります。

### ② 入力が不完全なら空欄を返す

```
IF(OR(COUNT(B2:D2)<>3,E2=""),"",計算処理)
```

`IF` 関数は次の構造です。

```
IF(条件, 条件がTRUEの場合, 条件がFALSEの場合)
```

つまり、

- 入力が不完全 → `""`（空文字列）を返す。
- 入力が揃っている → 計算処理を実行する。

という意味です。

### ③ 単位が「分」なら360で割る

```
IF(E2="分",(B2+4*C2+D2)/360, ...)
```

PERT法の計算式は以下です。

\\[ T=\frac{O+4M+P}{6} \\]

- \\(O\\)：楽観値
- \\(M\\)：最頻値
- \\(P\\)：悲観値

通常は6で割りますが、単位が「分」の場合は60で割って時間へ変換する必要があります。

したがって、

\\[ T=\frac{O+4M+P}{6\times60} =\frac{O+4M+P}{360} \\]

となります。

例えば、30分・60分・90分の場合、

\\[ \frac{30+4\times60+90}{360}=1 \\]

結果は 1時間 です。

### ④ 単位が「時間」なら6で割る

```
IF(E2="時間",(B2+4*C2+D2)/6,"")
```

すでに単位が「時間」なので、時間への変換は必要ありません。

例えば、1時間・1.25時間・2時間の場合、

\\[ \frac{1+4\times1.25+2}{6} =1.3333\ldots \\]

結果は約 1.333時間 です。

また、単位が「時間」でも「分」でもない場合は `""` を返します。

## 3. 処理の流れ

B2・C2・D2・E2の入力を確認

3つの数値と単位が揃っているか？

いいえ

空欄を返す

はい

単位を判定

「分」なら ÷360

「時間」なら ÷6

見積時間を返す

## 4. さらに簡潔に書く方法

今回のように、E列には「分」か「時間」のどちらかしか入力しない場合、次のようにも書けます。

```
=IF(OR(COUNT(B2:D2)<>3,E2=""),"",(B2+4*C2+D2)/6/IF(E2="分",60,1))
```

こちらも同じPERT計算を行います。

最後の部分がポイントです。

```
IF(E2="分",60,1)
```

- 「分」なら60で割る。
- それ以外なら1で割る（元の値を維持）。

ただし、簡潔版では「時間」「分」以外の値も時間として扱われます。 単位をプルダウンで厳密に管理している場合には有用ですが、入力ミスを検出したい場合は元の数式の方が適しています。

また、どちらの数式も3つの数値の大小関係（楽観値 ≤ 最頻値 ≤ 悲観値）までは検証していません。
